## 3. 맵

### 3.1. 크기 — 잠정 15×8
- 카메라가 고정이라 "한 칸이 손가락으로 집히는 크기"가 상한이다. 가로 화면에서 위 HUD·아래 손패를 빼면 판 세로는 약 64%뿐이라 **세로 8칸이 상한**, 키운다면 가로부터.
- 둘레 벽 칸은 없다. 맵 밖은 경계 검사가 막는다.

### 3.2. 목표물
- 맵 정중앙, 판정 1×2(15×8에서 정중앙이 되려면). 표식은 두 칸 경계 위의 둥근 물건 하나(지금은 잭팟 칩).
- 체력 100. 몬스터가 닿으면 종류별 피해(일반 1, 보스 10). 맞으면 표식이 튀고 빛나며 바닥에 고리(화면 흔들림 없음).

### 3.3. 포켓과 판 주사위 — 확정
- **포켓 6곳 고정**: 네 모서리 + 긴 변 가운데 둘. 번호는 앞쪽 변 왼쪽부터 1·2·3, 뒤쪽 변 왼쪽부터 4·5·6.
- 판 시작 때 **d6 3개**를 굴린다. **나온 눈의 포켓이 열리고**, 같은 눈이 겹치면 그 포켓에서 그만큼 더 나온다(출현 차례는 주사위 하나당 한 칸, 돌아가며 섞음). **눈의 합 = 시작 칩 수.**
- 결과를 먼저 정하고 연출은 보여 줄 뿐이다. 합만큼 칩을 못 놓으면 안에서 다시 굴린다 — 보여 준 합과 실제 칩 수가 늘 같다.
- **맵 운 보정 — 주사위가 문제를 내고, 검사는 풀 수 있는지만 본다.** 열린 구멍·겹침·보스 구멍은 굴림 그대로 두고, 생성 때 미로 계획(어시스트·봇과 같은 담금질·점수)을 몇 번 지어 본다. 가장 짧은 구멍이 기준(`MinShortestRoute`)보다 짧은 미로만 나오면 **칩만 다시 놓는다.** 한 번이라도 넘으면 통과.
- 생성은 두 단계다: 굴림 + 첫 칩 배치는 그 자리에서, 미로 검사·칩 다시 놓기는 워커 스레드에서. 검사가 안 끝났으면 판 주사위가 더 구르며 기다린다. 같은 시드 = 같은 맵.
- **시작 칩 배치**: 작은 무리(`ChipGroupSize`)로, 무리의 첫 칩은 이미 놓인 칩에서 가장 먼 후보에. 다른 무리에 닿는 칸은 건너뛴다.
- **판 주사위 연출**(약 3초, 실제 시간, 건너뛸 수 없음): 주사위가 분수처럼 흩어져 구르다 확정 → 하나씩 자기 번호 포켓으로 날아가 빠짐(포켓이 빛남) → 시작 칩이 하나씩 떨어짐 → 경로 표시가 첫 빛을 따라 그려지고 첫 웨이브를 기다린다. 연출 중에는 경로를 숨기고 카드 배치를 잠근다.
- 포켓 칸은 길은 되지만 주사위는 못 놓는다. 맵 안쪽 출현은 없다.

### 3.4. 칩
- 칸 위에 놓이는 물건이고 몬스터 길을 막는다. 한 칸에 **칩만 / 주사위만 / 칩 위 주사위**가 올 수 있고, 칩 위 주사위가 칩 효과를 받는다. 칩은 칸마다 1개(잠정).
- 판 시작 칩(종류는 칩 카드 가중치로 무작위)과 판 중 칩 카드(7.)로 생긴다. 빈 칸에 놓으면 새 벽(길을 완전히 막으면 거부), 칩 없는 주사위 칸에 놓으면 주사위가 올라앉는다.
- 표시: 칩 한 장, 색 = 효과(7장), 윗면에 검정 링.

### 3.5. 경로 규칙
- 몬스터는 목표물까지 최단 경로. 모든 경로를 막는 배치는 불가(출현 구멍마다 길 하나 보장).
- 막힘 판정은 4방향 칸, 걷는 길은 장애물 모서리에서만 꺾이는 곧은 길(any-angle). 몬스터 반지름의 원이 지나가는지로 봐서 모서리끼리 붙은 벽 사이로는 새지 않는다.
- **걷고 있는 몬스터를 가두는 배치는 허용, 갇힌 몬스터는 그 자리에서 죽는다**(목표물 피해 없음, 경험치는 준다, 분열하지 않는다).
- 경로 표시: 흐린 바탕선 + 출현 구멍에서 목표물까지 달리는 빛. 몬스터 길과 같은 계산을 쓴다.

## 4. 조작 및 화면 배치

| 영역 | 내용 |
|---|---|
| 맵 | 탭한 곳으로 영웅이 곧게 걸어간다(누른 채 끌면 목적지가 따라감) |
| 아래 | 손패(부채꼴, 같은 카드는 겹쳐 x2·x3). 끌어 맵에 놓는다 |
| 위 | 목표물 체력 · 웨이브 · 레벨/경험치, 보스가 있으면 보스 체력 바. 오른쪽 위에 일시정지·배속·설정 |

- 영웅은 판 안 어디든 걷는다(주사위·칩·목표물 위도). 막히는 건 판 밖뿐 — 길찾기 없이 곧게.
- 카드를 집는 동안·레벨업을 고르는 동안 게임이 느려진다(감속 요청 중 가장 느린 값). 배속(x1 → x2 → x3)은 감속 중엔 빠진다.
- 그리드 선은 평소 숨기고 카드를 끄는 동안·첫 웨이브를 기다리는 동안·일시정지 동안 켠다(멈춘 시간은 칸을 세며 계획하는 시간).
- 첫 웨이브는 ▶을 눌러 시작한다. 그 뒤 같은 버튼은 일시정지/재개.
- 카드는 **떼는 순간 바로 놓인다**(영웅이 걸어가서 놓지 않는다).

## 5. 카드

### 5.1. 종류 — 놓는 곳 기준 4종

| 종류 | 쓰는 법 | 내용 |
|---|---|---|
| 주사위 | 손패 → 칸 | 빈 칸에 놓기, 놓인 주사위에 얹기(6.3) |
| 칩 | 손패 → 빈 칸 / 칩 없는 주사위 칸 | 7장(7.) |
| 스킬 | 손패 → 주사위 / 칸 / 판 아무 곳 | 1회성(8.). 한 번의 드래그로 발동한다 |
| 영웅 강화 | 고르는 즉시 적용 | 이번 판 동안(10.4) |

### 5.2. 레벨업
- 처치 경험치로 레벨이 오르면 카드 3장 중 1장을 고른다(팝업, 고르는 동안 감속). 연달아 오르면 하나 고를 때마다 다음이 뜬다.
- 후보는 카드 한 장마다 가중치(지금 모두 1, 주사위 카드 한 종류의 몫 = 색 가중치 × 면체 가중치). 한 번에 같은 카드는 한 장. 쓸모없는 카드(치명타 확률 100%인데 치명타 확률 카드)는 거른다.
- **전용 카드**: 레벨업마다 15%로 지금 캐릭터의 전용 카드 1장 + 공용 2장(10.3).
- 보스 처치 = 카드 고르기 1번, 잭팟 보스 = 2번(레벨은 오르지 않는다).
- 고른 카드는 팝업의 그 자리에서 손패로 날아 들어간다.

### 5.3. 손패
- 상한은 장수가 아니라 **뭉치(겹친 카드 묶음) 수**. 새 종류가 들어와 넘치면 **기존 뭉치 하나가 무작위로 통째로 사라진다** — 아끼지 말고 바로 쓰고 정말 중요한 것만 남기라는 압박. 집은 카드는 사라지는 대상에서 뺀다. 지금은 테스트용으로 크게 열어 둔다(`MaxStacks`).
- 시작 손패: `SO_CardHandConfig.StartHand`.
- 카드 외형: 설명창이 곧 카드. 손패에서는 간단 모드(큰 아이콘 + 제목), 누르고 있으면 자세히 모드. 종류마다 테두리 색(칩 금색, 스킬 민트, 영웅 하늘).

### 5.4. 카드 글
- 한 줄 효과 + **그 카드만의 것**만 적는다. 모든 카드에 걸리는 시스템 규칙(각성 배율, 눈 최대 = 각성, 보스 저항, 스킬 처치는 포켓으로)·보면 아는 결과·쓰임새 힌트는 적지 않는다. "~다"체.
- 숫자는 적지 않고 `{필드}` 토큰으로 적어 SO 값으로 채운다.

## 6. 주사위 (타워)

### 6.1. 구성

| 요소 | 내용 | 정하는 것 |
|---|---|---|
| 면체 | d6 · d12 · d20 | 굴림 범위이자 **눈의 상한** |
| 색 | 빨강 · 초록 · 파랑 + 검정(색 없음). 섞이면 7색 | **공격 방식**과 등급(색 수) |
| 눈 | 굴려 나온 수 | 공격 세기, 치명타 확률(눈 × 1%) |

- 이름은 "빨강 육면체"처럼 색 + 면체. 빛처럼 섞인다: 빨+초 = 노랑, 빨+파 = 자홍, 초+파 = 하늘, 셋 = 하양.
- 레벨업 주사위 카드는 8색(빨·초·파·검정·노랑·자홍·하늘·하양) × 3면체 = 24종이 모두 나온다.

### 6.2. 놓기와 공격
- 칸에 놓으면 굴러 눈이 정해진다. 바닥에 놓으면 길을 막고, 칩 위면 길은 그대로이고 칩 효과를 받는다.
- 모든 주사위가 공격한다. 사거리 안에 맞힐 적이 없으면 쏘지 않고 기다린다. 즉시 맞힌다(투사체 없음).
- 능력치 = 기본 × (1 + 성장률 × (눈 − 1)^0.6). 눈으로 자라는 것은 공격력·공격 속도·공격 방식 값뿐이고 **사거리는 색마다 고정**(놓기 전에 사거리를 보고 자리를 고르므로).

### 6.3. 얹기(합성)
놓인 주사위에 주사위 카드를 얹으면 새로 굴려 합친다. 어떤 주사위 위에나 얹을 수 있다.

| 항목 | 규칙 |
|---|---|
| 눈 | 더한다. 상한을 넘친 만큼은 버린다 |
| 면체 | 큰 쪽 |
| 색 | 지금까지 얹은 색의 합집합 |
| 검정 | 눈만 더하고 색은 더하지 않는다 — 공격 방식을 지킨 채 키운다. 검정에 색을 얹으면 그 색이 된다(저금통) |
| 상한 | 같거나 작은 면체는 더 얹을 수 없다 |
| 칩 | 칸에 있으므로 얹어도 그대로 남는다 |

### 6.4. 등급 — 유지하기 어려울수록 강하다
- 얹어도 색이 그대로인 카드 수: 단색 2종(같은 색·검정) / 2색 4종 / 하양 8종 전부. **단색 = 기본이 강하지만 키우기 어렵고, 섞임 = 약하지만 크게 키우기 쉽다** — 손해만 보는 함정이 아니라 맞교환.
- 등급은 지금 색 상태(색 개수)로만 정하고 따로 배율을 두지 않는다 — 색마다 기본값을 SO에 직접 정한다.
- **역할**: 단색 = 한 마리를 확실히(보스·단단한 적), 2색 = 잡몹 떼, 하양 = 지원(디버프 칩 운반). 판 전체 위력은 범위형이 높은 게 맞다(파랑–자홍 정도 차이가 적당선).

### 6.5. 색과 공격 방식
빛의 3원색 = 능력치 성격 — **빨강 = 힘, 초록 = 속도, 파랑 = 사거리**. 단색은 단일, 섞인 색은 부모 성격을 물려받고 범위가 붙는다.

| 색 | 공격 방식 | 성격 | 각성 (눈 20) |
|---|---|---|---|
| 빨강 | 강타(단일) | 강하고 느린 한 방 | 매 공격 확정 치명타 |
| 초록 | 속사(단일) | 같은 적을 이어 맞힐수록 세짐(상한 없음, 대상이 바뀌면 처음부터) | 공격 속도 2배 |
| 파랑 | 저격(단일) | 긴 사거리, 멀리 있는 적일수록 셈 | 사거리 1.5배 |
| 노랑 | 폭발 | 가장 많이 휘말리는 곳을 맞히고 반경 안에 퍼짐 | 반경 2배 |
| 자홍 | 관통 | 사거리 끝까지 얇은 직선, 가장 많이 꿰뚫는 쪽을 겨냥 — 곧은 통로에 강하다(미로와 엮이는 유일한 공격) | 선 폭 2배(**다시 정할 것**) |
| 하늘 | 체인 | 선두에서 가까운 적으로 튀며 감쇠, 피해가 작아지면 멈춤 | 감쇠가 줄어 멀리 이어짐 |
| 하양 | 파동 | 자기 주변 사거리 안 전부, 사거리 짧음 | 두 겹(두 번째는 약하게) |
| 검정 | 기본 단일 | 약한 단일 | 없음 — 눈 20이 되면 7색 중 하나로 바뀌어 바로 각성 |

- 겨냥은 관통·폭발 = 가장 많이 휘말리는 곳, 나머지 = 선두(목표물까지 남은 길이 가장 짧은 적).
- **최대 체력 피해**: 모든 색이 한 방마다 맞은 적 최대 체력 × 값(`SO_DiceType.MaxHealthDamage`, 색마다 다름, 하양·검정 0)을 더한다. 눈으로 자라지 않는다. 고정 피해만으로는 웨이브 체력 복리를 따라가지 못해 넣었다. 공격 방식 배율·오버드라이브·공격력 칩은 함께 곱한다.
- 고화력과 속사는 피해 공식(방어력 고정 차감, 9.3)만으로 갈린다 — 따로 규칙을 만들지 않아도 상성이 생긴다.
- 특정 색이 없으면 못 잡는 면역은 두지 않는다. 상성은 효율 차이로만.

### 6.6. 치명타
- 확률 = 눈 × 1%(윗면 숫자가 곧 확률). 배율은 모든 주사위 공통이고 피해에만 적용.

### 6.7. 각성
- **어떤 색이든 d20 눈 20에 닿으면** 각성한다(세기 없이 온전한 효과). 더 큰 면체가 없어 더 얹을 수 없으므로 각성은 풀리지 않는다(리롤 등으로 눈이 내려가면 풀림).
- **공통**: 한 방 피해 전체(고정 + 최대 체력 피해) ×2(`AwakenDamageScale`). 색마다 각성 효과는 그 위에 더한다.
- **각성 = 자기 공격 방식의 극대화.** 약점을 메우거나 다른 역할을 넘보는 효과는 쓰지 않는다.
- 눈에 보여야 한다(커진 고리, 굵은 선, 금색 눈 글자).

### 6.8. 표시
- 눈은 주사위 윗면 숫자로만. 놓을 때 사거리 고리, 얹을 때 고스트(합친 결과의 면체·색)와 지금 눈.
- 놓거나 얹으면 제자리에서 솟아나 굴러 멈춘 뒤 눈이 보인다(실제 시간 — 판정은 기다리지 않는다).

## 7. 칩 — 색 = 효과

칩은 바꿀 수 없으므로 칩 하나가 주사위 카드 한 장보다 확실히 나아야 한다(붙은 주사위 가치 +50% 안팎). 주사위와 같은 빛의 3원색 뜻을 강화 3장에, 섞인 색 4장에 디버프를 둔다.

| 칩 (색) | 종류 | 효과 |
|---|---|---|
| 공격력 (빨강) | 강화 | 이 주사위 공격력 +% |
| 공격 속도 (초록) | 강화 | 이 주사위 공격 속도 +% |
| 사거리 (파랑) | 강화 | 이 주사위 사거리 +% |
| 취약 (하양) | 디버프 | 맞은 적이 잠시 **모든 공격에** 더 아프게 맞는다(방어력 빼기 전에 곱함, 화상에도) |
| 둔화 (노랑) | 디버프 | 잠시 느리게 |
| 얼림 (하늘) | 디버프 | 잠시 멈춤, 풀린 뒤 면역 |
| 화상 (자홍) | 디버프 | 몇 초 동안 초당 최대 체력 %, 방어력 무시 |

- 디버프는 **겹치지 않고 센 쪽 하나만 남는다**(다시 걸면 시간만 새로) — 길목마다 하나면 충분하다. 이 장르는 디버프를 깔고 시작하는 게 기본이다.
- 디버프 넷은 "1분 동안 모든 적에게 걸려 있을 때 피해 몇 %와 같은가"로 맞춘다(지금 넷 다 +30~35%). 화상만 적이 버티는 시간에 비례해 초반에 약하고 후반에 세다 — 성격으로 둔다.
- 공격력 칩 vs 취약: 주사위 혼자면 공격력 칩이, 같은 길목을 둘 이상이 덮으면 취약이 낫다.
- 효과는 눈과 무관한 고정값이고, 그 주사위가 맞히는 모든 적(폭발 파편 포함)에게 건다.
- 상태 표시는 체력바 아래 작은 네모(걸린 것만, 색 = 거는 칩 색). 몸 색은 특성이 쓴다.

## 8. 스킬 카드

**규칙**
- 한 번의 드래그로 발동한다(대상을 두 번 고르는 스킬은 만들지 않는다). 쓰는 순간 눈에 띄는 움직임이 있어야 한다.
- **적 대상 스킬은 판 전체다** — 판 위 모든 적에게 쓰고, 판 위 아무 곳에나 놓으면 쓴다(놓은 자리는 레이크만 쓴다). 대상이 없어도 쓸 수 있다(버리기). 모두 즉발.
- 적 대상 스킬 피해 = **영웅 공격력 × 배율**, 영웅 치명타를 굴리고 방어력·보스 저항을 지난다(모든 피해가 같은 공식). 다 죽이면 특징이 일을 하지 않으므로 "반 이상 깎는" 세기가 기준이다.
- **스킬로 죽은 적은 가장 가까운 포켓으로 날아 들어간다**(주사위로 잡은 것과 눈으로 구분).
- 이동 방해 저항(보스)은 끌기·밀어내기 거리와 멈춤 시간에도 곱한다.
- 이름은 **테이블 게임 용어**, 이름·설명은 실제 동작과 일치시킨다.
- 스킬 추가 예정 없음(필요해지면 그때).

| 대상 | 스킬 | 효과 |
|---|---|---|
| 주사위 | 잭팟 | 눈을 상한으로(d20이면 각성) |
| 주사위 | 리롤 | 면체(모델이 있는 면체 중 같은 확률)와 눈을 다시 굴린다 |
| 주사위 | 오버드라이브 | 몇 초간 공격력·공격 속도 배율. 영웅 오버드라이브(10.5)와 같은 효과 |
| 주사위 | 페인트 7색 | 색을 덮어씀(눈 그대로) → 공격 방식·등급이 바뀜 |
| 판 | 올인 | 목표물 체력을 최대로 채우고 모든 주사위 눈을 다시 굴린다(면체 그대로) |
| 적 전체 | 포켓 | 피해 뒤 체력이 처형선 아래인 적을 처치(보스 포함) |
| 적 전체 | 레이크 | 피해 뒤 놓은 점으로 끌어모은다(보스도) |
| 적 전체 | 백스핀 | 피해 뒤 오던 길로 튕겨낸다 |
| 적 전체 | 체크메이트 | 피해, 체력이 가장 높은 적(왕) 하나는 훨씬 큰 배율 |
| 적 전체 | 체크 | 피해 뒤 잠시 멈춤(얼림 면역 무시, 면역을 남기지 않음) |
| 캐릭터 전용 | 10.3 표 | 풀 하우스 · 브레이크 샷 · 리스핀 · 하우스 엣지 · 세븐스 헤븐 · 캐시 아웃 |

- 주사위 대상은 놓인 주사위에만. 같은 색 페인트·상한인 주사위에 잭팟은 막는다(쓸모없이 버려지지 않게).
- 미리보기: 적 대상은 판 전체를 연한 초록으로 + 레이크 모음점·체크메이트 왕 표시. 주사위 대상은 쓴 뒤 모양의 고스트.

## 9. 몬스터·웨이브·보스

### 9.1. 몬스터와 특성
- 몬스터 = 기본 종류 하나 + 특성 몇 개. 겹치면 배율(속도·체력)은 곱하고 고정값(방어력·재생)은 더한다.
- 겉모습: 구체 하나에 **띠 무늬** — 색 있는 특성이 없으면 크림, 하나면 그 색, 둘이면 띠 = 앞·양끝 = 뒤. 보스는 크기로.
- 다음 웨이브 특성은 미리 알리지 않는다(겉모습으로 보고 대응).

| 특성 | 정의 | 맞서는 색 / 칩 |
|---|---|---|
| 단단함 | 받는 피해에서 방어력만큼 뺀다(최소 % 보장) | 강타·저격·관통 / 취약 |
| 빠름 | 빠르고 체력이 조금 낮다 | 속사·파동 / 둔화 |
| 분열 | 죽으면 체력이 적은 조각 2마리로(한 번만, 조각은 경험치 없음·목표물 피해 1) | 폭발 |
| 재생 | 초당 최대 체력 % 회복 | 강타·속사 / 화상 |
| 보스 | 체력 큼, 느림, 목표물 피해 큼, 받는 피해·이동 방해 저항(9.3) | 단일형 |

- 떼(약한 적 다수)는 특성이 아니라 웨이브 구성이다.

### 9.2. 웨이브
- 무한 모드. 웨이브를 다 내보내고 맵의 몬스터가 모두 죽으면 바로 다음 웨이브(쉬는 시간 0 — 배치는 전투 중에 하는 게 기본).
- 마릿수 = 기본 + 웨이브마다 증가, 상한(`MaxCount`). 넘으면 한 마리 체력을 키워 웨이브 체력 합을 맞춘다.
- 체력 배율은 **복리**(웨이브마다 ×(1 + `HealthCompound`)) — 무한 모드는 "언젠가 반드시 진다"가 보장돼야 한다.
- 구성: 앞 웨이브는 목록대로 특성을 하나씩 소개하고, 그 뒤는 무작위(일반 2가지 × 특성 1~2개). 5웨이브마다 보스 웨이브. 여러 가지면 번갈아 나온다.
- 후반(`ExpBoostAfterWave`) 이후 처치 경험치 ×2.
- 한 웨이브에 무너지는 구조는 그대로 둔다(장르 특성). 억울하다는 반응이 나오면 먼저 정보(결과 화면의 마지막 웨이브 특성·샌 수, 판 중 "곧 뚫림" 신호)를 더한다.

### 9.3. 피해 공식
```
배율 피해 = 기본 피해 × 치명타 배율(터졌을 때) × (1 + 취약)
최종 피해 = max(배율 피해 − max(방어력 − 관통, 0), 배율 피해 × 최소 %) × 받는 피해 배율(보스 저항)
```
- 배율을 먼저 곱하고 방어력은 나중에 — 치명타(큰 주사위의 장점)가 단단한 적에게 특히 강하다.
- 보스 저항은 방어력을 뺀 뒤에 곱한다(먼저 곱하면 단단한 보스가 의도보다 몇 배 단단해진다).
- 화상은 방어력을 받지 않는다(최대 체력 비율). 보스 저항은 받는다.
- 피해는 정수: 맞힌 피해는 반올림·최소 1, 화상은 1 미만 나머지를 모았다가 준다.

### 9.4. 보스와 잭팟 보스
- **보스 구멍**: 판 주사위가 가장 많이 들어간 포켓. 그 포켓 빛은 판 내내 보스 색 — 보스가 지날 길을 미리 알고 미로를 짠다.
- 체력 = 그 웨이브 일반 몬스터 체력 합 × `BossHealthShare`. 속도 절반, 목표물 피해 10. 분열을 받지 않는다.
- **받는 피해 90% 저항, 이동 방해 90% 저항**(출처 무관, 받는 쪽에서 줄인다). 모든 피해·효과에 걸리는 보스 규칙이라 카드마다 적지 않는다.
- **잭팟 보스**: 보스가 25%로 잭팟 보스가 된다(보스 웨이브가 시작될 때 정해지고 보스 포켓이 금색으로). 겉모습만 금색이고 나머지는 보스와 같다(새면 똑같이 10). 보상만 2배.
- 죽는 연출: 일반은 제자리에서 톡 사라지고, 보스는 가장 가까운 포켓으로 크게 날아 들어간다.

## 10. 영웅

### 10.1. 정체와 역할
- **바니**(바니걸·바니보이). 테이블 게임을 지휘한다.
- 역할: **스킬 발사대**(적 대상 스킬 위력 = 영웅 공격력 비례) + **특성으로 판의 흐름을 기울인다** + 자동 공격 + **오버드라이브**(10.5).
- 몬스터는 영웅을 통과한다(몸으로 막지 않는다).

### 10.2. 능력치
| 능력치 | 쓰는 곳 |
|---|---|
| 공격력 | 영웅 공격 피해, 적 대상 스킬 위력의 기준 |
| 공격 속도 | 영웅 공격 간격(초당 횟수) |
| 이동 속도 | 영웅 이동 |
| 사거리 | 영웅 공격 사거리(강화하지 않음 — 캐릭터마다 고정) |
| 치명타 확률·피해 | 영웅 공격과 스킬에만(주사위 치명타와 따로). 확률 100%를 넘친 몫은 치명타 피해로 옮긴다 |
| 투사체 | 한 번에 던지는 카드 수(1에서 시작, 강화 카드로만) |

- **단계 1~6**: 캐릭터를 열 때 능력치마다 d6을 굴려 단계를 정한다. 6단계 = 캐릭터의 한계값, 1단계 = 한계값 × 하한 비율(`StageFloorRatio`), 사이는 고르게. 리롤로 올린다(12.4).
- 영웅 수치는 캐릭터마다 다르다 — 잠정 캐릭터 값으로 규칙을 판단하지 않는다.

### 10.3. 캐릭터 = 특성 하나 + 전용 카드 한 장
둘이 한 주제다. 캐릭터 이름은 나중에 사람 이름으로 바꾸므로 **특성 이름으로 부른다.** 전용 카드는 판을 뒤집는 카드라 강하게 둔다.

| 특성 (캐릭터 SO) | 특성 효과 | 전용 카드 | 카드 효과 |
|---|---|---|---|
| 레인보우 (BunnyGirl) | 레벨업 후보가 항상 서로 다른 종류 | 풀 하우스 (주사위) | 잠시 그 주사위가 7색 공격 방식을 모두 동시에 쓴다 |
| 브레이크 (Princess) | 기본 능력치가 매우 높다(갈고리 없음) | 브레이크 샷 (판) | 잠시 영웅 공격력·공격 속도 배율 |
| 더블 오어 낫싱 (Hedonist) | 주사위는 1 아니면 최대만(놓기·얹기·리롤·올인) | 리스핀 (판) | 눈이 1인 주사위만 다시 굴린다 |
| 더블 (Gambler) | 레벨업마다 확률로 후보 하나가 x2(고르면 두 장) | 하우스 엣지 (판) | 잠시(게임 시간) 처치 경험치 배율 |
| 777 (LuckyBoy) | 후보에 육면체 없음, 놓을 때(얹기 포함) 늘 7 | 세븐스 헤븐 (판) | 잠시 판 위 모든 주사위 각성 |
| 빌더 (Builder) | 레벨업 주사위 면체가 큰 쪽으로 기운다 | 캐시 아웃 (칸) | 칸의 주사위·칩을 거둬 각각 몇 장씩 손패로(주사위는 면체·색만) |

- **특성 원칙**: 캐릭터당 하나. 기본은 장점, 위험·보상형을 일부. 깎이기만 하는 단점은 넣지 않는다. 숫자 보너스도 카드 선택·배치 판단이 달라지면 좋다. 주사위 굴림에 끼어드는 특성은 타워 주사위만(판 주사위는 건드리지 않는다).
- **구현 원칙**: 특성이 자주 생기고 엎어지므로 시스템은 특성 종류를 모른다. 시스템이 자기 폴더에 작은 갈고리 인터페이스를 두고 `TraitHooks.Find<T>()`로 묻는다(없으면 원래대로). 특성은 `SO_HeroTrait`를 잇고 필요한 갈고리만 구현한다.
- 전용 카드는 `SO_HeroCharacter.ExclusiveCard`, 공용 목록에는 넣지 않는다.
- **밸런스 목표**: 평균(도달 웨이브)만 비슷하게. 저점·고점이 널뛰는 것은 개성이다. 같은 시드끼리 짝지어 시드 20개 이상으로 잰다. 브레이크의 장점은 기본 능력치라 능력치를 맞춘 비교로는 드러나지 않는다.

### 10.4. 영웅 강화 카드 — 8장
- **곱 갈래 4장**: 공격력 · 투사체 +1 · 치명타 확률 +%p · 치명타 피해 +%p. 셋이 곱해져 카드 수의 세제곱으로 큰다 — 그래서 종류를 늘려 곱 갈래 공급을 묽혔다.
- **디버프 4장**(마킹 = 취약 · 슬로우롤 = 둔화 · 콜드 덱 = 얼림 · 틸트 = 화상): 칩 디버프의 센 버전(약 2배 — 영웅이 맞힌 적에게만 걸리므로). 색·아이콘은 그 칩 것. 여러 장이면 **지속 시간만 더하고 세기는 그대로**(세기를 더하면 곱 갈래가 하나 더 생기고 화상은 무한 모드를 깬다).
- 고르는 즉시 적용, 이번 판 동안만. 공격 속도·이동 속도 강화는 없다(캐릭터 개성으로만).
- 투사체: 사거리 안 가까운 적부터 한 장씩, 적이 모자라면 앞에서부터 다시. 카드마다 치명타·방어력이 따로 적용된다(단단한 적엔 공격력, 떼엔 투사체).

### 10.5. 오버드라이브 — 영웅이 올라탄 주사위
- 영웅이 올라탄 주사위는 오버드라이브 상태가 된다(스킬 카드 오버드라이브와 같은 효과·값). 카드 시간이 남은 주사위는 카드 시간을 먼저 쓴다.
- **대가**: 올라탄 시간이 쌓일 때마다 그 주사위 눈이 1씩 **영구로** 깎인다(주사위마다 쌓임, 적이 판에 있을 때만 흐름). 눈 0이면 공격을 멈추고 벽으로만 남는다. 각성 주사위는 첫 눈이 더 오래 걸려 깎인다.
- 주사위 위에서는 영웅 자동 공격이 주사위 사거리로 친다(더 길 때만).
- 영웅 자리에 "가장 좋은 곳" 하나가 생기지 않게 효과에 대가를 붙여 돌려쓰게 한 것이다.

### 10.6. 미정
- 발동 컷인: 어느 스킬에 넣을지 기준(자주 쓰는 스킬마다 나오면 과하다).

## 11. 판 구조와 밸런스

### 11.1. 판 구조 — 확정
- 무한 모드. 판의 끝은 목표물 체력 0뿐. 기록은 **클리어한 웨이브**(진 웨이브 − 1).
- 흐름: 로비 → 게임 시작(영웅이 판으로 뛰어듦) → 판 주사위 연출 → ▶로 첫 웨이브 → … → 결과 → 다시 하기(판 치우기 → 새 판) 또는 로비로. 씬을 나누지 않고 판 상태를 코드로 되돌린다(봇도 같은 길).
- 판 중 설정: 판이 멈추고 **포기하기**(게임 오버와 같다, 확인 창 없음).

### 11.2. 밸런스는 나중에 AI 시뮬레이션으로
- 시스템을 다 만든 뒤 봇으로 판을 돌리고 기록(CSV)을 AI가 분석해 SO 수치를 고친다. 결과는 봇 실력에 묶이므로 **상대 비교**(같은 봇으로 캐릭터·카드끼리)에 쓰고 마지막 손맛은 사람이 맞춘다. 그때까지 수치는 잠정.
- **새 코드가 지킬 것**(CLAUDE.md에도 있음): ① 게임 시간은 갱신 함수가 받는 값(판 시스템은 `OnGameUpdate`, UI·연출은 `OnUpdate`) ② 게임 행동은 UI 없이 코드로 부를 수 있게 ③ 판 결과에 영향을 주는 난수는 `GameRandom`(시드로 재현) ④ 측정할 값은 이벤트로.
- 판 시스템은 고정 걸음으로 돈다 — 같은 시드·같은 선택이면 같은 판.

### 11.3. 측정
- `Measure/WaveLog`: 웨이브마다 정리 시간·처치·새어 나간 적·목표물 피해(무적이어도)·체력·레벨·출처별 피해(주사위 8색·영웅·스킬·화상·오버드라이브)·고른 카드·후보 종류·몬스터 특성. `RunLogs/run_*.csv`(에디터·개발 빌드만).
- 판 시스템은 이벤트만 내고 연결은 `GameScene`이 한다.
- 판 전체 비율은 사실상 마지막 웨이브들의 비율이다(체력 복리라 마지막 5웨이브가 피해의 절반).

### 11.4. 봇
- 사람과 같은 길만 부른다(레벨업 `AutoChoose`, 손패 → `CardPlacement`·`SkillCaster`, 영웅 `Hero.MoveTo`).
- **미로**: 맵 생성 검사가 지은 미로(`MapData.MazePlan`)를 첫 계획으로 믿고, 계획 밖에서 벽이 바뀔 때만 워커 스레드에서 다시 찾는다(받는 시점이 게임 시간으로 정해져 재현된다). 점수 = 출현 구멍마다 걷는 거리 + 길 칸마다 사거리 안 주사위 수.
- **판단**(사용자 판을 교본으로): 구간별 카드 점수, **메인 딜 구간**(범위 주사위·칩·사거리를 한 구간에 모은다), 디버프 칩은 몰림이 큰 곳, 오버드라이브·스킬은 메인 딜 구간이 뚫릴 것 같을 때만. 판단 값은 `SO_BotConfig`.
- 켜기: A = 보면서(배속), Shift+A = 빠른 시뮬(그리지 않고 한 프레임에 많은 걸음 — 결과는 같다). 여러 판 돌리기·캐릭터 순환·비교 묶음·고정 시드를 설정할 수 있고 요약 `RunLogs/bot_summary_*.csv`를 남긴다.
- 봇 기준선이 사람 판과 비슷한 수준이라 미로 우선형과 따로 비교하지 않는다.

### 11.5. 테스트 도구 (에디터·개발 빌드)
- F1 테스트 창: 기능(테스트 키 목록) · 카드 넣기 · 영웅(캐릭터·단계·강화) · 메타 · 기록.
- 테스트 키: R 새 맵 · C 바로 레벨업 · U/K 칩·스킬 카드 · N/Shift+N 웨이브 건너뛰기 · E 경험치 막기 · I 무적 · J 다음 보스를 잭팟으로 · L 언어 · B 로비로 · A/Shift+A 봇 · T 색 시험.
- **색 시험**(T): 미로 계획 칸 전부를 한 색 d20 눈 20으로 깔고 영웅·칩·레벨업 없이 모든 적에게 디버프를 건 채 웨이브 처리 비율을 잰다(`RunLogs/color_test_*.csv`).

## 12. 로비·메타

### 12.1. 전제
- **오프라인 싱글.** 서버·상점·유료 재화·운영 이벤트 없음. 세이브는 로컬.
- 비교 대상은 판매형 로그라이크의 메인 화면이다. **메타의 중심은 캐릭터(해금 + 능력치 리롤).** 영구 능력치 강화는 넣지 않는다(기록이 누적 강화량이 되고 시뮬 변수가 는다).

### 12.2. 로비 화면
- 로비는 `GameScene` 안의 상태다 — 뒤의 테이블이 곧 판이라 영웅이 판으로 뛰어드는 연출이 끊기지 않게.
- 왼쪽: 로고, 난간에 걸터앉은 3D 캐릭터, 이름 버튼(누르면 캐릭터 선택 창).
- 오른쪽 패널: 특성 카드(이름 + 설명) → 능력치 주사위 칸(눈 = 단계, 6단계는 "최대" 태그, 눌러 고르면 리롤 버튼) → 최고 기록.
- 오른쪽 아래: 게임 시작. 위: 재화, 설정.
- 세로 화면은 위에서부터 쌓는다(패널은 묶음째 옮긴다).

### 12.3. 캐릭터 선택 창
- 얼굴 격자, 세로 스크롤. 바깥을 눌러 닫는다(X 없음). 열린 캐릭터는 누르면 바로 선택되고 닫힌다.
- 잠긴 캐릭터: 검은 실루엣 + 이름 + 해금 조건 + 진행도. 조건을 채우면 "눌러서 열기" — **해금은 저절로 되지 않는다**(누르는 순간이 연출 자리).
- 얼굴은 일러스트(`Portrait`), 없으면 3D 모델 사진.

### 12.4. 해금·재화·리롤
- 해금 조건은 `SO_MetaConfig.Unlocks`(최고 웨이브 말고는 모두 **누적**). 목록에 없는 캐릭터는 처음부터 열린다. 처음 열린 캐릭터는 레인보우(BunnyGirl).
- **판 보상 = 클리어한 웨이브 × (10웨이브마다 하나씩 얻는 d6 눈의 합)** — 판 시간이 웨이브의 제곱쯤으로 늘므로 보상도 제곱으로 늘어 분당 재화가 고르다. 10웨이브 전에 지면 0.
- 리롤: 재화를 내고 능력치 하나의 주사위를 다시 굴려 **높을 때만** 바꾼다. 구르는 동안 또 누르면 이어서 구른다.
- 판 밖 주사위 연출(리롤·해금·결과 보상)은 같은 2D 주사위를 쓴다. 결과를 먼저 정하고, 빈 주사위가 돌다 착지할 때 처음 눈이 보인다.
- 세이브: 재화, 캐릭터별 열림·단계·최고 기록, 마지막 캐릭터, 누적 진행도. 캐릭터 키는 SO 에셋 이름(바꾸면 기록이 끊긴다).

### 12.5. 설정
- 언어(번역표의 언어 수만큼, 이름은 그 언어 자기 말), 음량 셋(전체·배경음·효과음). 진동은 아직 없다.

- 소리.

## 13. 열린 문제

- 자홍 각성(지금 선 폭 2배 — 체감 없음).
- 칩 칸당 1개 → 2개 여부, 레벨업 가중치(지금 모두 1 — d20·페인트·잭팟 희귀도는 최종 조정 때).
- 손패 상한 값(지금 테스트용으로 크게).
- 7색이 실제 칸 크기·조명에서 구분되는지, 색약 대응.
- 하양 → 페인트 흐름이 지나치게 강한지.
- 봇 규칙 `MazeOutsideZoneFirst`(미로 칸 구간 밖부터)를 지울지 — 끈 채로 20시드 × 6캐릭터 측정 후 결정.
- 실기기 확인: 칸 크기·드래그 조작감, 세로·폴더블 화면, d20 두 자리 숫자.
- 웨이브 공식의 최종 모양과 수치(시뮬레이션 때).
