# 카드 아이콘

카드 아이콘(스킬·전용·영웅 강화·칩·빅 스택·페인트·주사위)을 코드로 그려 PNG로 뽑는 도구. Unity가 가져가지 않게 `Assets/` 밖에 둔다.

## 스타일 (2026-11-04 사용자 확정)

페르소나 5 앱 아이콘 스타일 — 플랫, 먹·흰·강조색 하나.

- **먹색 판**: 기호 실루엣을 부풀려 대충 따라간다(정해진 판 모양이 아니다). 두께 8.
- **바깥 테두리**: 흰 줄 + 카드 종류 색(`SO_CardHandConfig`의 `*CardColor` — 주사위 자홍, 스킬 민트, 전용 보라, 영웅 파랑, 칩 주황).
- **기호**: 흰 면 + 먹 선. **강조색 한 곳** = 카드 SO의 `IconColor`. 주사위·페인트·칩은 의미 색(색 = 뜻)이라 강조색 자리가 그 색이다.
- **어긋난 그림자**: 기호를 종류 색으로 오른쪽 아래에 한 번 더.
- **주사위**: 정면 실루엣(d6 사각, d12 십각형, d20 육각형) + 가운데 면에 면 수 숫자(Black Han Sans). 가운데 면 = 색, 둘레 면 = 한 단 어둡게.
- **빅 스택**: 칩 그림에 테만 금색.
- 안쪽 무늬(칩 홈·주사위 면 조각 등)는 `D(...)`로 표시해 판 모양 계산에서 뺀다 — 넣으면 무늬 모서리가 바깥 테두리를 울퉁불퉁하게 만든다.

## 파일

| 파일 | 내용 |
|---|---|
| `icons.js` | 그림 소스 — 도우미, `ICONS`(기호), `diceSvg`, 카드 목록·강조색 |
| `list.js` | 내보낼 목록 — 프로젝트 경로 · 종류 색 · 기호 |
| `index.html` | 미리보기(카드 틀 위에 손패·크게). 브라우저로 연다 |
| `export.html` | 내보내기용 페이지(`export.py`가 찍는다) |
| `export.py` | PNG 내보내기 |

## 쓰는 법

1. `icons.js`의 `ICONS`에 기호를 더하거나 고치고, `index.html`을 브라우저로 열어 본다(새로고침).
2. 새 카드면 `icons.js`의 카드 목록과 `list.js`에 한 줄 더한다.
3. `python Tools/CardIcons/export.py` — 전부 다시 뽑는다. 일부만: `python Tools/CardIcons/export.py Icon_Skill_Rack`.
   - 필요: Edge(헤드리스 캡처), node, Pillow. Edge 경로가 다르면 환경 변수 `EDGE`.
   - 512px, 그림마다 여백을 잘라 칸을 꽉 채운다(가장자리 2%).
   - 있는 파일은 덮어써 GUID(카드 연결)가 유지된다. 새 파일은 메타만 만들어 두므로 카드 SO의 `Icon`에 연결하고 `TintIcon`을 끈다.
4. 주사위 카드 아이콘은 `SO_Dice_*`의 `CardIcons`(면체마다)에 연결한다. 없으면 `CardView`가 면체 흰 그림에 색을 곱해 쓴다.
